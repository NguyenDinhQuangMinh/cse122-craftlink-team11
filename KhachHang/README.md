# Khách hàng (Buyer) — SV1

Thư mục dành cho 6 màn hình vai Khách hàng, STT 1–6 trong `docs/screen-inventory.md`:

1. Trang chủ & Khám phá — `index.html`
2. Chi tiết sản phẩm — `product-detail.html`
3. Tạo Brief yêu cầu tùy biến — `custom-order-brief.html`
4. So sánh & Chọn Proposal — `proposal-comparison.html`
5. Thanh toán & Xác nhận — `checkout-confirmation.html`
6. Quản lý Đơn hàng & Hồ sơ — `customer-dashboard.html`

**Hiện tại chưa có mã nguồn ở đây.** SV1 mới bàn giao tài liệu mô tả, các tệp HTML trên chưa tồn tại trong repo. Ghi rõ để bảng kiểm kê không bị hiểu là đã làm xong.

Quy ước khi code về: CSS và JS của riêng vai này đặt ở `css/` và `js/` trong thư mục này, không lấy file của `ThoThuCong/` hay `QuanTriVaKiemDuyet/` dùng chung. Màn hình nào có nhiều bước thì tách thành `NN-ten-man-hinh/index.html` kèm `js/main.js` như phân hệ nghệ nhân.
